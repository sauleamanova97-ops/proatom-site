# ProAtom.kz — сайт

Простой новостной сайт из двух страниц:
- `index.html` — лента новостей (шапка + главная новость + список постов)
- `contacts.html` — страница контактов

## Как добавить новость

Открой `index.html` в любом текстовом редакторе и скопируй один блок `<article class="post" ...> ... </article>` целиком, вставь его первым в списке `<div class="feed">` и поменяй:

- `id="post-1"` → уникальный номер (`post-7`, `post-8`...) в трёх местах внутри блока (id, ссылка в заголовке, `data-target` у кнопки)
- текст в `.post-tags` — теги (например «Казахстан», «Уран», «Технологии»)
- заголовок в `<h3><a>...</a></h3>`
- `.post-excerpt` — короткий анонс (1–2 предложения, видно сразу)
- `.post-full` — полный текст поста (открывается по кнопке «Читать полностью»)
- дату в `.meta`
- картинку `src="assets/..."` — можно загрузить свою фотографию в папку `assets/` и указать её имя файла

## Картинки

Сейчас вместо фотографий использованы простые SVG-иллюстрации в фирменных цветах (папка `assets/`), потому что у меня нет доступа к твоим реальным фото. Просто клади свои картинки в `assets/` (jpg/png) и меняй путь в `src`.

## Публикация

Самый простой способ — GitHub Pages, раз у тебя уже есть GitHub:
1. Создай новый публичный репозиторий, например `proatom-site`
2. Залей туда все файлы этой папки (`index.html`, `contacts.html`, `style.css`, `assets/`)
3. В настройках репозитория → Pages → Source → выбери ветку `main` и папку `/root`
4. Через пару минут сайт будет доступен по адресу вида `https://<твой-логин>.github.io/proatom-site/`

Если позже захочешь подключить свой домен `proatom.kz` — это тоже настраивается в том же разделе Pages (поле Custom domain), скажи мне и я подскажу шаги.

## Автопубликация из бота

Твой новостной бот уже собирает и переводит новости в JSON/текст. Следующий логичный шаг — научить его вместо (или в дополнение к) отправке в Telegram дописывать новый блок `<article>` в `index.html` и коммитить изменение в репозиторий сайта через GitHub API. Это можно сделать отдельным шагом, когда будешь готова — просто скажи.
